## ✨ Features & Highlights

- 💥 **Explosive Brick Shattering**: Glowing neon bricks with multi-hit durability and particle debris explosions.
- ⚡ **Dynamic Power-Up Capsules**:
  - 🔵 **Multi-Ball**: Splits active balls into multiple bouncing energy spheres.
  - 🟢 **Wide Paddle**: Expands paddle width for effortless saves.
  - 🔴 **Laser Cannons**: Mounts dual blasters to shred bricks ahead.
  - ⚡ **Speed Ball**: High-velocity power shots that pierce through defenses.
- 🎵 **Web Audio Synth**: Real-time chime synthesizers for paddle bounces, wall hits, and power-up collection.
- 📱 **Mobile & Desktop**: 1-to-1 touch drag tracking and smooth mouse navigation.

## 🕹️ Controls

| Action | Desktop / Mouse | Mobile / Touch |
| :--- | :--- | :--- |
| **Move Paddle** | Move Mouse Cursor | Drag Finger across bottom screen |
| **Launch Ball** | Left-Click or `[SPACE]` | Tap Screen |
| **Pause** | `[ESC]` or `[P]` | Tap Pause Button |
